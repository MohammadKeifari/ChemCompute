# Examples

These walkthroughs match the gallery at the top of the [README](https://github.com/MohammadKeifari/ChemCompute#examples). Each page includes runnable code and figures generated by ChemCompute itself.

## Regenerate figures

From the repository root:

```bash
python docs/generate_readme_figures.py
```

Output is written to `docs/images/`.
